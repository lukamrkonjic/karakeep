Magpie

A browser that keeps things. Open it from the tray, or use the tray icon on its own to save whatever you have just copied.

Create one in Karakeep under Settings → API Keys. It needs both assets:readwrite and bookmarks:readwrite to archive a page. Leave this empty to fall back to the key compiled into this build. It is stored in plain text in the app's user-data folder either way, so treat it like a password.

For sites whose drags carry no data at all (Pinterest) and for media that can't be dragged (a YouTube video): right-click → Copy image link / Copy video URL, then left-click the tray icon — the picker opens right by your cursor. Nothing appears unless you ask for it.
