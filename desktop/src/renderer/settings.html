Karakeep Drop

Drag an image or video anywhere on screen and a list picker appears under the cursor. Drop it on a list to save it.

Create one in Karakeep under Settings → API Keys. It is stored in plain text in this app's user-data folder, so treat it like a password.

The way in for sites whose drags carry no data at all (Pinterest) and for media that can't be dragged (a YouTube video): right-click → Copy image link / Copy video URL and the picker appears. Only fires for media links copied in a browser — ordinary copying is ignored.

Lower feels more immediate; higher stops the picker appearing when you only meant to select some text.
